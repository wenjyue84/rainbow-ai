  - Scoring report generation with: fallback_id, fallback_text, max_relevance_score, matched_intent, recommendation

### Patterns discovered
- Knowledge.json structure: `{static: [{intent, semantic_category, response: {en, ms, zh}}]}`
- TF-IDF-based scoring avoids external API dependencies for testing
- Recommendation tiers: KEEP (high confidence), REWRITE (medium confidence), DELETE (low confidence)
- Cosine similarity scoring is deterministic and reproducible
- Lowest-scoring fallbacks sorted ascending in report (worst first)
- Report includes statistics: total fallbacks, low-relevance count, average/min/max scores

### Gotchas avoided
- Used English response field for scoring (primary language) with fallback to first available language
- Truncated fallback_text to 100 chars in output to prevent report verbosity
- Recommendation suggestions only included for REWRITE/DELETE, not KEEP (cleaner output)
- Handled semantic_category field addition via sed when Edit tool had Unicode dash issues
- Build uses esbuild (not tsc) - pre-existing type errors in context-window-benchmark.ts don't block
