1.  Create the new `suggest-keywords.ts` script, using a library like `yargs` for parsing command-line arguments (`profile`, `days`).

6.  Use a library like `natural` to perform the TF-IDF calculation on the cleaned texts for each intent group.
7.  From the TF-IDF results, extract the top 2-3 terms with the highest scores for each intent. These are the `suggested_keywords`.
8.  Format the final results into the specified JSON structure and print to standard output.

*   **Performance:** Processing 30 days of data could be memory-intensive. The script should process data in streams or chunks if memory becomes an issue.
*   **Zero Results:** The script should handle cases where no escalated conversations are found for the given period and return an empty or informative message.
*   **Keyword Quality:** TF-IDF might suggest single letters, numbers, or nonsensical terms. Apply a post-filter to suggestions (e.g., minimum length of 3 characters).
