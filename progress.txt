*   **Cache Framework:** `frappe.cache` should be used to persist the circuit breaker's state across different server workers and restarts. A custom DocType for logging is not necessary; use standard logs.

**3. Implementation Approach:**

*   **Concurrency:** Multiple simultaneous requests could cause race conditions. Use `frappe.cache().lock()` when updating the circuit breaker state to ensure atomicity.
*   **HALF-OPEN Logic:** Ensure that after the 60-second timeout, the circuit enters a HALF-OPEN state, allowing only one request to pass. If it fails, the circuit must re-open immediately.
