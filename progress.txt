    - Starts with base score 0.2 for non-empty messages
    - Adds keyword matching boost (up to 0.2) based on intent-specific keywords
    - Adds recency factor (up to 0.25) for recent messages
    - Penalizes generic phrases (up to -0.25)
    - Maps 10+ intents to keyword lists (booking, wifi, checkin, pricing, facilities, complaint, etc.)
  - `filterByRelevance(messages, intent, threshold=0.3, minMessages=8)`: Filters low-relevance messages
    - Always preserves most recent 8 messages
    - For older messages, keeps only if score >= 0.3
    - Returns messages in original order

- **Chat Engine Integration** (`src/assistant/chat-engine.ts`):
  - After intent classification, filters conversationHistory if length > 8
  - Logs pruning results: "Filtered history from X to Y messages for intent Z"
  - Prevents hallucination from outdated booking requests or old check-in questions

    - Keyword matching scores differently for different intents
    - Recency bonus for recent messages
    - Assistant messages get slight relevance boost
    - Empty messages score 0
    - Score clamping to [0, 1]

    - **Core acceptance criteria**: Old extend_stay request filtered when classifying room_type intent
    - Booking context preserved when filtering for booking intent (validates keyword relevance)
  - All 8 tests passing ✓

### Patterns discovered
- Intent keyword matching uses case-insensitive substring matching (`.includes()`)
- Scoring uses multiplicative and additive components for flexibility:
  - Base 0.2 (non-empty) + keyword match (0-0.2) + assistant boost (0.1) + recency (0-0.25) - penalties
  - Allows message type, intent, and temporal context to combine naturally
