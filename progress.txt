Here is the technical brief based on the JSON provided:

**File to Modify:**
*   `package.json`

**NPM Scripts to Change/Add:**
*   `build`: This existing script will be completely replaced.
*   `check`: This is a new script to be added.

**Implementation Approach:**
1.  **Add Dependency:** Install `esbuild` as a dev dependency: `npm install esbuild --save-dev`.
2.  **Update Build Script:** Modify the `"build"` script in `package.json`. It should first run the `esbuild` command, then chain the file copy command. A pre-build step to clean the `dist` directory is also recommended.
    *   `"build": "esbuild src/index.ts --platform=node --packages=external --bundle --format=esm --outfile=dist/index.js && node -e \"require('fs').cpSync('src/assistant/data','dist/assistant/data',{recursive:true});require('fs').cpSync('src/public','dist/public',{recursive:true})\""`
3.  **Add Check Script:** Add a new script for type-checking only: `"check": "tsc --noEmit"`.

**Edge Cases & Gotchas:**
*   The `fs.cpSync` command requires Node.js v16.7.0+. If the project uses an older version, a different method (e.g., `fs-extra` or a shell script) will be needed.
*   For robust builds, consider adding `rimraf dist` (requires `npm i rimraf --save-dev`) before the `esbuild` command to ensure a clean output directory.
