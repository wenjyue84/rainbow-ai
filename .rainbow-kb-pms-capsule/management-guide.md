## Daily Operations

### Check-in Procedure
1. Verify guest identity (passport or IC)
2. Confirm booking in PMS2
3. Assign capsule (even = lower deck, odd = upper deck)
4. Collect payment if not prepaid
5. Issue key card (RM10 deposit for stays >7 nights)
6. Show guest to capsule, explain WiFi and facilities
7. Record check-in in PMS2

### Check-out Procedure
1. Retrieve key card from guest
2. Inspect capsule for damages
3. Process any outstanding charges
4. Mark checkout in PMS2
5. Refund key card deposit if applicable

## Common Issues

### Key Card Not Working
1. Re-swipe slowly at reader
2. Check if card is near magnets/phones
3. Re-encode at front desk if needed

### Maintenance Requests
- Log issue in PMS2 under the unit
- Tag maintenance status on the unit
- Contact repair team if urgent

### Guest Complaints
- Listen, acknowledge, apologize
- Check if issue can be resolved immediately (extra towel, AC adjustment, etc.)
- Escalate to Jay for unresolved issues
- Log complaint in PMS2 notes

## PMS2 Staff Tools

### Cash Drawer (`/cash`)
Record daily cash transactions for audit purposes.
1. Navigate to `/cash` in PMS2 staff dashboard
2. Select type: **Cash In** or **Cash Out**
3. Enter amount (RM) and reason (e.g. "Guest payment", "Change fund", "Expense")
4. Submit — entry is timestamped and tied to your staff login
5. Day-end: tally against physical cash drawer before handover

### Aircond Maintenance (`/aircond`)
Log and track air-conditioning issues per capsule unit.
1. Navigate to `/aircond` in PMS2 staff dashboard
2. Select affected unit number
3. Log issue type: Not cooling / Dripping / Noisy / Not turning on / Other
4. Set status: **Pending** / **In Progress** / **Resolved**
5. Add notes (contractor name, scheduled date, parts ordered)
6. Notify Jay via WhatsApp for issues unresolved after 24 hours

## Emergency Procedures
