### Patterns discovered

- knowledge.json structure varies per profile:
  - Default profiles use array with "id" and "profile_id" fields
  - PMS/management profiles use simpler array structure
  - Templates stored under "intent": "booking_confirmation" in "static" section

- Placeholder pattern: `{{fieldName}}` uses simple string replacement
  - No complex templating engine needed
  - Clean, human-readable template syntax

- Template fallback: If language not found, automatically falls back to English
  - Ensures robustness across language variants
